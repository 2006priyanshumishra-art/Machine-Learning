# Machine Learning & Artificial Intelligence Lab

This repository contains practical lab assignments covering fundamental to advanced machine learning and artificial intelligence algorithms, ranging from data preprocessing and search agents to regression, classification, clustering, dimensionality reduction, and ensemble methods.

Developed by **Priyanshu Mishra** ([@2006priyanshumishra-art](https://github.com/2006priyanshumishra-art)).

---

## 📚 Assignments Overview

| # | Notebook | Topic | Key Techniques / Algorithms | Dataset |
|:---:|:---|:---|:---|:---|
| **1** | [Assignment 1](Assignment1.ipynb) | **Data Preprocessing & EDA** | Handling missing values, Label Encoding, Feature Scaling (StandardScaler), Train-Test Split | `gender_classification_v7.csv` |
| **2** | [Assignment 2](Assignment2.ipynb) | **Simple Reflex Agent** | Rule-based conversational reflex agent for appointment booking | — |
| **3** | [Assignment 3](Assignment3.ipynb) | **Search Algorithms** | Uninformed search strategies: Breadth-First Search (BFS) and Depth-First Search (DFS) | — |
| **4** | [Assignment 4](Assignment4.ipynb) | **Knowledge Representation & Inference** | AND/OR Graphs, Knowledge Base construction, Logical reasoning | — |
| **5** | [Assignment 5](Assignment5.ipynb) | **Linear & Polynomial Regression** | Simple Linear Regression, Polynomial Regression (Degree 2), 3D Regression Plane visualization, Metrics (MSE, MAE, $R^2$) | `housing.csv` |
| **6** | [Assignment 6](Assignment6.ipynb) | **Decision Trees & Naive Bayes** | Decision Tree Classifier (Gini Impurity, Information Gain / Entropy), Gaussian Naive Bayes, Confusion Matrix | `Admission_Predict.csv` |
| **7** | [Assignment 7](Assignment7.ipynb) | **Clustering Algorithms** | K-Means Clustering (Elbow Method), Agglomerative Hierarchical Clustering, Divisive Clustering, Dendrograms | `Iris.csv` |
| **8** | [Assignment 8](Assignment8.ipynb) | **Dimensionality Reduction (PCA)** | Principal Component Analysis (PCA), Eigenvector/Eigenvalue decomposition, Explained variance & Scree plots | `Wine.csv` |
| **9** | [Assignment 9](Assignment9.ipynb) | **Ensemble Learning & SVM** | Support Vector Machines (SVM), Random Forest Classifier, AdaBoost Classifier, Model Evaluation | `car_evaluation.csv` |

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.8+
- **Core Libraries:**
  - `numpy`
  - `pandas`
  - `matplotlib`
  - `seaborn`
  - `scikit-learn`
  - `scipy`

To install the required dependencies:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn scipy jupyter
```

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/2006priyanshumishra-art/Machine-Learning.git
   cd Machine-Learning
   ```

2. Launch Jupyter Notebook or JupyterLab:
   ```bash
   jupyter notebook
   ```

3. Open any assignment notebook (`Assignment1.ipynb` – `Assignment9.ipynb`) and run the cells sequentially.
